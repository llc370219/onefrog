# 面板布局与测试版渠道

OneFrog v0.1.31 正式发布。本次调整面板首页，并可以在设置里切换正式版和测试版。

## 面板布局

- 「需要处理」和「订阅」之间的小卡片改成自动化。
- 服务监控下移，独占一整行。
- 只列出已勾选的监控项，不列出全部服务器。同一行从左到右是状态、监控项、所在服务器、类型，异常项排在前面。

## 更新渠道

- 「设置 → 关于与更新」可以在「正式版」和「测试版」之间切换，改完会立刻重新检查。
- 正式版只提示正式发布。测试版同时看正式版和 vX.Y.Z-beta.N。
- 点「立即升级」时，只把官方镜像改成 latest 或 beta，并记住渠道。用更早安装脚本装的机器，第一次切换请重新运行一次安装命令。

## 升级方式

在面板「设置 → 关于与更新」检查并升级；也可以在安装 OneFrog 的服务器上执行以下命令，安装或切换到正式版：

```bash
curl -fsSL https://raw.githubusercontent.com/llc370219/onefrog/main/install.sh | sudo OF_CHANNEL=stable bash
```

使用自定义安装目录的用户需继续指定原来的 `OF_INSTALL_DIR`。原目录升级会保留账号、设置和数据，升级时容器会重启。

项目地址：https://github.com/llc370219/onefrog
