# 自动化、随机密钥、群聊与 Bot 头像

OneFrog v0.1.29 正式发布。本次新增自动化，可以让 Bot 按计划在后台执行任务；保险箱支持随机生成密钥；群聊和 Bot 单聊的历史分开保存，每个 Bot 有了自己的头像。

## 自动化

在「模块 → 自动化」里写下要 Bot 做的事，选好执行时间（每天、每周、按间隔或只运行一次），Bot 会在后台按时执行，适合定时巡检、备份检查这类重复工作。

- 每次运行的过程和结论写进执行它的 Bot 名下一段带「自动化」标签的单聊，可以随时打开查看或接着追问；操作历史里也会记一条成功或失败。
- 列表里每条自动化都能「立即运行」、暂停或修改。面板首页可以加一张自动化卡片，显示即将运行的任务和最近结果。
- 后台运行没有人在线审批：需要确认的命令会被拒绝。审批模式是「关闭」的自动化按「智能」执行，也可以设为「仅规划」只出方案。
- Bot 只能操作为这条自动化选定的服务器，不能向你提问，也不能派工给其他 Bot。
- 每次最长 10 分钟，最多同时运行 2 个，最多保存 50 个。上一次还没结束时，这一次会跳过。
- 时间按 OneFrog 服务器所在时区计算；面板停机期间错过的运行，恢复后不会补跑。
- 配置加密保存在 `automations.enc`。Token 用量计入「自动化」来源。

详见 [自动化](../自动化.md)。

## 随机生成密钥

数据库密码、Redis 口令、JWT 签名密钥这类不需要你记住的值，可以让服务端随机生成：

- 面板「添加密钥」和「轮换」里切到「随机生成」，选长度（8–256，默认 32）和字符集。
- Bot 会调用 `generate_secret` 生成，只拿到名称和 `{{secret:名称}}` 引用，不会自己编密码。
- 值用系统安全随机数生成后立即加密，浏览器、对话记录和模型都看不到明文。已有的同名密钥不会被覆盖。

## 群聊与 Bot 单聊

- 左侧分成「Bot 单聊」和「群聊」两块。每个 Bot 的单聊历史挂在它下面，再点它会回到最近的一段单聊，「新话题」可以另开一段。
- 「新建群聊」先勾选参与的 Bot（主控固定参与），群里每条回复都显示说话 Bot 的头像和名字。

## Bot 头像

每个 Bot 自动分到一张头像，显示在侧栏、Bot 页和对话里。32 个 Bot 以内互不重复。

## 升级方式

在面板「设置 → 关于与更新」检查并升级；也可以在安装 OneFrog 的服务器上执行以下命令，安装或切换到正式版：

```bash
curl -fsSL https://raw.githubusercontent.com/llc370219/onefrog/main/install.sh | sudo OF_CHANNEL=stable bash
```

使用自定义安装目录的用户需继续指定原来的 `OF_INSTALL_DIR`。原目录升级会保留账号、设置和数据，升级时容器会重启。
