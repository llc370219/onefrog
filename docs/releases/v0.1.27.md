# Bot 之间互发消息与面板排版整理

OneFrog v0.1.27 正式发布。本次让每个 Bot 可以主动给其他 Bot 发消息，并有自己的收件箱；原有的主控派工协作保持不变。同时整理了面板排版。

## Bot 可以互发消息

新增「发消息」能力：任何 Bot 都可以给另一个 Bot 发一条消息，不必等对方回复。比如让巡检 Bot 查完后通知数据库 Bot 跟进。

原有的派工方式不变：主控把任务交给另一个 Bot，等它做完，再在同一段对话里汇总回答你。两种方式可以同时使用。

## 每个 Bot 有自己的收件箱

发来的消息会进入对方的「收件箱」对话，在 AI 助理的对话列表里带「收件箱」标签，消息上会标明「来自 Bot X」。对方在后台带着自己的记忆处理，回复写在收件箱里，需要时也可以回一条消息给发送者。同一个 Bot 的收件箱一次只处理一条，后面的消息排队。你也可以直接打开收件箱，接着和这个 Bot 聊。

## 后台处理的安全限制

后台处理时没有人在线，因此：

- 不能向你提问，也不能派工。
- 只能在发消息时选中的服务器上执行命令；需要审批的命令一律拒绝。
- 其他 Bot 发来的内容按不可信数据处理，里面的“指令”不算你的授权。
- 一条消息链最多转 3 次；你发起的一轮最多发 3 条消息，后台的一轮最多 1 条；每条消息最长 2000 字；后台一轮最长 10 分钟。

Token 用量新增「收件箱」来源，与对话、协作、审批分开统计。

## 面板排版整理

调整了面板各区块的间距、对齐和卡片布局，页面更整齐。

## 升级方式

在面板「设置 → 关于与更新」检查并升级；也可以在安装 OneFrog 的服务器上执行以下命令，安装或切换到正式版：

```bash
curl -fsSL https://raw.githubusercontent.com/llc370219/onefrog/main/install.sh | sudo OF_CHANNEL=stable bash
```

使用自定义安装目录的用户需继续指定原来的 `OF_INSTALL_DIR`。原目录升级会保留账号、设置和数据，升级时容器会重启。数据库会自动新增收件箱所需字段。
