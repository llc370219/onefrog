# 测试版：修复三网测速省份选择与配置应用

- 首页和服务器列表的「选择省份」会直接打开对应节点的测速设置。
- 选择省份后点击「保存并应用」，通过已保存的 SSH 凭据更新节点配置并重启探针，显示应用中、成功或失败状态，失败后可重试。
- 保留原探针上报凭据、上报地址、采样间隔、网卡及其他检测目标；服务重启失败时恢复原配置。
- 支持更换省份或关闭三网测速，并保留手动接入和重置探针凭据入口。
- 更换省份后等待新测速结果，历史图不再混入其他省份的数据。

应用配置需要节点已安装 OneFrog 探针、已确认 SSH 主机指纹，以及 root 或免密 sudo 权限。配置成功后通常在一分钟内显示新的测速结果。

验证：完整 Go 测试、go vet、前端构建和 GitHub CI 通过；配置保留、原凭据继续有效、SSH 失败与服务重启回滚均有回归测试；浏览器验证浅色和深色、桌面和 390px 手机宽度下的保存与反馈流程。
