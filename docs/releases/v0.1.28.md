# Bot 独立对话、主控对话与服务监控

OneFrog v0.1.28 正式发布。本次改了 AI 助理的对话方式：点某个 Bot 就和它一对一聊，它能独立干活；「新对话」由主控协调多个 Bot。服务管理也升级为服务监控，可以自选监控项并在后台轮询。

## 独立对话：每个 Bot 都能独立干活

在左侧点某个 Bot，就只和这个 Bot 一对一对话。它只读写自己的记忆，看不到其他 Bot 的记忆。

每个 Bot 都能独立完成任务：执行服务器命令、接入服务器、操作管理面板、安装探针、开发自定义模块。审批规则和以前一样，有风险的操作会弹卡片让你确认。

遇到别的 Bot 更熟悉的事，它会自己决定请对方当场协助，或者发消息异步通知，协助过程显示在对话里。

## 主控对话：多个 Bot 协作

点「新对话」进入主控对话。主控接收任务，按需自动拉其他 Bot 一起做。你可以在右侧「协作 Bot」列表或输入框下方的协作选项里，随时剔除或拉入 Bot。被剔除的 Bot 不会被派工，也收不到这段对话发出的消息。

原来的「主 Bot」下拉已去掉。左侧对话列表里，独立对话标着「Bot 名 · 独立」，主控对话标着「主控对话」，重新打开历史对话会回到原来的模式。

## 保留的限制

- 被其他 Bot 叫去协助时，Bot 只做交给它的那件事，不改面板、不装探针，需要改的写进汇报，由正在和你对话的 Bot 去做。
- 管理资产的 Bot 不执行服务器命令。
- Bot 不能停用或删除自己，也不能停用或删除主控；主控只能由你在设置里停用或删除。

## 服务监控

「服务管理」改名为「服务监控」。检测出服务列表后，可以勾选 systemd 服务、Docker 容器或监听端口加入监控，点「保存监控」生效。

- 面板在后台按设定间隔轮询（30 到 3600 秒，默认 60 秒），保存后立即检测一次；每台服务器最多监控 100 项。
- 每一项显示待检测、正常、异常、缺失或无法判断。第一次变为异常或缺失时写一条失败历史，恢复后写一条成功历史。
- 监控配置和最近状态加密保存在 `servicewatch.enc`，重启面板后继续轮询。
- 新增接口 `GET /api/services/watch` 和 `PUT /api/services/watch`。

## 升级方式

在面板「设置 → 关于与更新」检查并升级；也可以在安装 OneFrog 的服务器上执行以下命令，安装或切换到正式版：

```bash
curl -fsSL https://raw.githubusercontent.com/llc370219/onefrog/main/install.sh | sudo OF_CHANNEL=stable bash
```

使用自定义安装目录的用户需继续指定原来的 `OF_INSTALL_DIR`。原目录升级会保留账号、设置和数据，升级时容器会重启。
