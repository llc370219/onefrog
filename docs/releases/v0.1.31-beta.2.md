# 设置里可以切换测试版

OneFrog v0.1.31-beta.2 测试版。只推送给装了测试版的机器，正式版安装不会收到提示。

## 更新渠道

- 「设置 → 关于与更新」增加「更新渠道」：正式版 / 测试版。改完会立刻重新检查。
- 正式版只提示正式发布。测试版同时看正式版和 vX.Y.Z-beta.N。
- 点「立即升级」时，只把官方镜像改成 latest 或 beta，并记住渠道。
- 用更早安装脚本装的机器，第一次切换仍要重新运行一次安装命令，换上新的升级程序。

## 升级方式

已经装了测试版的机器，在面板「设置 → 关于与更新」检查并升级。从正式版切换到测试版，在安装 OneFrog 的服务器上执行：

```bash
curl -fsSL https://raw.githubusercontent.com/llc370219/onefrog/dev/install.sh | sudo OF_CHANNEL=beta bash
```

使用自定义安装目录的用户需继续指定原来的 `OF_INSTALL_DIR`。原目录升级会保留账号、设置和数据，升级时容器会重启。

项目地址：https://github.com/llc370219/onefrog
