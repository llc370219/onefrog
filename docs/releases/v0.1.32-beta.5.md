# 群聊项目记忆与宿主机代码工作区

- **群聊项目**：可为群聊命名。群内 Bot 共用该项目的工作记忆，派工结论留在本群。旧群聊保留聊天历史，从空白的项目记忆开始。
- **模型渠道**：自定义 API Key 渠道可选 Responses 或 Chat Completions。Responses 支持执行工具并将结果回传给模型继续处理，现有渠道默认协议不变。
- **部署宿主机**：「添加服务器」可预填宿主机地址。接入仍使用专用 SSH 账号和已确认的主机指纹；旧安装可按安装文档补充 Compose 的宿主机地址映射。
- **代码工作区**：在左侧打开已接入服务器上的 Git 仓库，浏览和编辑源码、查看状态和差异，或交给助手修改并运行测试。助手写文件和执行命令需要逐次批准。宿主机需要 Git、Python 3.9+ 和有源码目录访问权限的非 root SSH 账号。
