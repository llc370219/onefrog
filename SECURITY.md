# 安全策略 / Security Policy

## 报告漏洞

请**不要**在公开 issue 中报告安全问题。请在本仓库的 **Security → Report a vulnerability** 中私下提交，内容尽量包括：

- 受影响的版本或提交；
- 复现步骤或概念验证；
- 可能的影响（例如绕过命令审批、读取 SSH 凭据、越权访问）。

我们会尽快确认并在修复发布后致谢（如你愿意）。

## 支持的版本

只有最新发布版本会获得安全修复。

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Use **Security → Report a vulnerability** in this repository to report privately, and include the affected version or commit, reproduction steps and the potential impact (for example bypassing command approval, reading SSH credentials or privilege escalation).

Only the latest release receives security fixes.
