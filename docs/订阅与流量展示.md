# 订阅与流量展示

「订阅」可记录服务器、域名、软件会员等服务，关联服务器可留空。新增记录默认使用 USD，旧记录的原币种与金额不变。服务器 IP、配置和月流量额度放在可选区域。

## 汇总口径

- **订阅数**：当前记录数，不包含历史订阅。
- **7 天内到期**：从今天起到第 7 天，包含两端日期；已过期或已停用的记录不计入。
- **折合月费**：月付金额 + 季付金额 ÷ 3 + 年付金额 ÷ 12；不含一次性费用和历史订阅。各记录先按本币折算到月，再按参考汇率汇总。
- **历史订阅**：已到期且未启用续费，或已手动结束的记录。保留原始记录，移出当前订阅和月费；可在历史页选择「续费 / 恢复」，修改到期日并保存。

仍启用续费但尚未更新到期日的记录留在当前订阅中，可更新日期，或点击「不再续费」结束订阅。手动续费的记录在过期后也可重新编辑日期恢复。

## 月费显示币种

默认 USD，可在汇总卡片切换 CNY、EUR、GBP、CAD、HKD、JPY、AUD、SGD。选择在当前浏览器记忆，并同步到首页卡片和订阅页。

参考汇率来自 [Frankfurter 公共 API](https://frankfurter.dev/)，按约 6 小时缓存，仅供预算估算。服务端只发送固定的公共币种代码，不向汇率服务发送订阅名称、金额或账号。界面标注汇率日期；刷新失败但已有缓存时标注缓存汇率，且限制失败后的请求频率。

无汇率或不支持的币种（例如 USDT、自定义币种）保留原币金额，并明确列出未折算部分，不假设 USDT 与 USD 恒等，也不将缺失汇率当作零费用。

## 未设置流量额度

服务器卡片上方依次显示本月 **Out / In / Total**，Total = 出站 + 入站。下方双色条左侧为 Out、右侧为 In，长度表示两者占总流量的比例，**不代表流量额度使用率**。没有数据时显示「—」，零流量时显示零和空条。

已登记月流量额度时继续按计费方式展示额度进度，不改变额度统计口径。
