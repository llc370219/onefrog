# 接入 Frog Bot AI 助理

- **AI 助理架构升级**：主「AI 助理」接入 Frog Bot，短问题由快模型快速回复，耗时操作派给后台 Agent 并在服务器持续运行，支持步骤展示、暂停、恢复、重试与审批。
- **定时唤醒器**：集成 Frog Bot 持久化计划与调度器，支持单次、每天与每周提醒任务，到点自动分派并汇报。
- **凭据与多租户隔离**：Frog Bot 采用每个账号独立的数据目录与加密保险箱；远程服务器操作必须通过显式卡片逐条确认，与 OneFrog 现有 SSH 审计无缝衔接。
- **原有会话保留**：多 Bot 运维会话保留在「运维会话」菜单中，原有代码工作区与面板功能不受影响。
