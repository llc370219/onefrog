# 测试版：探针卡片流量行统一样式，可以直接设置额度

- 没设月流量额度时，流量行和设了额度的一样：左边是图标和「流量」，右上角用斜线隔开显示「Out / In / Total」，下面的方块按出站、入站的比例着色。卡片较窄时，数值会换到下一行，不再被截断。
- 没设额度时，「流量」旁边有「设置额度」。点开可以直接填每月额度和计费方式，保存后卡片马上显示「已用 / 额度」。服务器还没登记资产时，会先打开资产登记。
- 设了额度的卡片，点「流量」旁边的计费方式（如「双向」）可以修改额度。

验证：前端类型检查通过；用模拟数据在浅色 / 深色、桌面 / 390px 截图核对；在卡片上设置额度后，卡片立即切换为「已用 / 额度」。
