# 自动化

自动化让 Bot 按计划在后台执行一段固定的指令，类似聊天助手里的定时任务。适合每天巡检磁盘和服务、每小时看一次日志错误、每周汇总资源使用这类重复工作。

## 创建

打开「模块 → 自动化」，点「新建自动化」，填写：

- 名称：最多 40 字。
- 要 Bot 做的事：写清楚检查什么、发现问题时怎么处理，最多 4000 字。不要把密码直接写进任务；需要凭据时用 `{{secret:名称}}` 引用。
- Bot 和服务器：后台运行时 Bot 只能操作这里选中的服务器。不选服务器时只能做不需要服务器的事。
- 频率：每天某个时间、每周某天某个时间、固定间隔（15 分钟到 7 天）或只运行一次。
- 审核方式：见下文。

整个 OneFrog 最多保存 50 个自动化。时间按 OneFrog 服务器所在的时区计算；只运行一次的任务按浏览器里选的时间换算。

## 运行与结果

到点后 Bot 在专属对话里收到这段指令并独立完成。对话在 AI 助理的列表里带「自动化」标签，可以随时打开查看过程，也可以接着追问。每次运行还会在历史记录里留下一条，状态为成功或失败。

自动化卡片显示上次状态、上次和下次运行时间，以及回复的前 300 字或失败原因。「立即运行」会马上跑一次，不影响原来的计划。只运行一次的任务跑完后自动停用。

为了不互相干扰，有这些规则：

- 同一个自动化上一轮还没结束时，到点的这一轮直接跳过。
- 全部自动化同时最多运行 2 个，其余排队。
- 每轮最长 10 分钟，超时记为失败。
- OneFrog 停机期间错过的时间点不会补跑，启动后从下一个时间点继续。

## 安全

后台运行时没有人在线审批，所以：

- Bot 不能向你提问、不能弹出密码卡片、不能派工给其他 Bot。
- 需要你确认的命令一律拒绝。审批设为「关闭」时，自动化按「智能审批」处理，有风险的命令不会执行。
- 选「仅规划」时 Bot 只给出方案，不执行命令。
- 只能在选中的服务器上执行命令。

自动化配置加密保存在数据目录的 `automations.enc`。Token 用量计入「自动化」来源。

## 接口

| 接口 | 说明 |
| --- | --- |
| `GET /api/automations` | 列出自动化 |
| `POST /api/automations` | 新建，体为 `{"name","prompt","bot_id","server_id","schedule":{"kind":"daily|weekly|interval|once","time":"09:00","weekday":1,"minutes":60,"at":"…"},"approval_mode":"|smart|plan","enabled":true}` |
| `PUT /api/automations/:id`、`DELETE /api/automations/:id` | 修改 / 删除。删除不会删掉已有对话和历史 |
| `POST /api/automations/:id/run` | 立即运行一次；正在运行时返回 409 |

写请求需带 `X-OneFrog-CSRF: 1` 请求头。
