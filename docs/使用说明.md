# 使用说明

## 导航与账号

主菜单依次为「面板」「AI 助理」「模块」「服务器」「Bot」「密钥保险箱」「变更记录」。「AI 助理」「模块」的二级目录显示在主菜单右侧，可以收起；窄屏下主菜单缩成图标栏。

点击左下角头像进入个人账号：上传 PNG/JPEG/WebP 头像（最大 256 KB）、修改显示名称，或在「登录与安全」修改用户名和密码（需要当前密码；修改后其他设备的会话失效）。密码以 bcrypt 哈希保存。

## 接入服务器

在「服务器」页点「接入服务器」，填写地址、SSH 端口、用户名和认证方式（密码或私钥）。

- **请使用权限受限的专用用户**，不要使用 root。
- 首次连接会显示服务器的 SSH 主机指纹（SHA256），请在服务器上用 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` 核对后再确认。确认并连接成功后才保存指纹。
- 之后如果指纹变化，连接会被拒绝并提示，不会自动覆盖。确认是正常原因（如重装系统）后，在「SSH 测试」弹出的指纹不一致窗口中重置，再重新核对。修改服务器地址或端口也会清除已保存的指纹。
- 未确认指纹的服务器不能被 Bot 执行命令。

## AI 助理

- 新对话默认不选服务器。只有手动选中的服务器允许执行远程命令，模型指定其他主机会被拒绝。
- 可以选择主 Bot（切换会开始新会话），默认允许调用所有已启用的 Bot，也可以剔除部分协作 Bot（由服务端校验）。
- 模型下拉可为当前对话临时选择模型，不改变 Bot 的持久绑定。
- 审批方式在首次登录时由你选择，也可在设置中修改或按对话临时切换。「智能审批」下只读命令直接执行，有风险的命令会弹窗显示目标服务器、命令、风险原因和 AI 说明的目的，由你批准或拒绝；5 分钟无响应视为拒绝。「关闭审批」下命令直接执行。其他模式见 [设置与模型配置.md](设置与模型配置.md#命令审批)。
- 重新打开历史会话时恢复模型、Bot 范围和审批选项，但服务器仍需手动选择。

### 附件

支持选择、拖入和粘贴文件：

- PNG、JPEG、WebP 图片和 PDF：每个最多 5 MB（需要所选模型支持相应输入）。
- UTF-8 文本、配置、日志、代码：每个最多 256 KB，不接受二进制内容。
- 每轮最多 4 个附件、合计 12 MB；历史附件上下文超过 24 MB 时提示新建对话。

附件按账号校验权限，以 AES-GCM 加密保存在数据目录；文本在发给模型前会做密钥脱敏。附件内容只是待分析的数据，其中的指令不构成操作授权。

## Bot 管理

「Bot」页列出每个 Bot 的名称、职责、当前模型、启用状态和 Token 用量。可以重命名、修改职责与工作指令、绑定独立的渠道和模型或恢复跟随默认。停用的 Bot 不能发起对话或接受派工。

Token 用量只按模型响应中的 `usage` 累计，不做估算，分为对话、协作、审批三类来源。

## 密钥保险箱

Bot 只看到密钥名称。命令中写 `{{secret:名称}}`，执行时才在服务端替换，命令输出中出现的明文会被打码。

## 服务器探针

一台服务器一张卡片，展示 CPU、内存与 Swap、根分区磁盘、网络速率与累计流量、延迟与丢包、运行时间、负载、TCP 连接数和进程数。设计参考了 [Komari](https://github.com/komari-monitor/komari) 的轻量探针思路，代码为独立实现。

接入：

1. 在服务器卡片点「接入探针」。
2. 填写被监控节点能访问的主控地址，**请使用 HTTPS 地址**（上报凭据随每次请求发送）；不要给远程节点填 `127.0.0.1`。
3. 按需填写网络检测目标、采集间隔和网卡，生成该节点专属的上报凭据并下载配置和脚本（凭据只出现在下载的配置里）。
4. 在节点上准备 Python 3.8+（ICMP 检测需要 `ping`），把两个文件放在同一目录，执行 `chmod 600 onefrog-probe.json && python3 onefrog-probe.py ./onefrog-probe.json`。长期运行请自行配置 systemd 等服务管理器。

脚本只读取 `/proc` 和文件系统容量、按配置执行 ping 并上报，不接收任何远程指令。超过 90 秒未上报显示离线。服务端只保存凭据的 SHA-256，保留每个节点最近 120 个采样（默认 15 秒一次，约 30 分钟），不是长期时序数据库。

## 资产与订阅

在「模块 → 资产与订阅」记录 VPS、域名等的提供商、套餐、计费周期、金额、付款日、到期日、自动续费等信息（账号栏只保存备注，不保存密码）。

- 剩余价值 = 本期金额 × 剩余天数 ÷ 周期总天数；已到期或停用为 0；14 天内到期标为即将到期。
- 折合月费：年付 ÷ 12、季付 ÷ 3，一次性费用不计入。
- 「模块构建」Bot 可以通过对话登记、修改、删除这些记录，它不能执行服务器命令。

数据加密保存在 `assets.enc`。

## 主要接口

所有接口都需要登录；写请求需带 `Content-Type: application/json`（上传附件为 multipart）和请求头 `X-OneFrog-CSRF: 1`。

| 接口 | 说明 |
| --- | --- |
| `GET /api/auth/me`、`PUT /api/auth/profile` | 当前账号 / 修改资料与登录信息 |
| `GET /api/sessions`、`GET /api/sessions/:id/messages` | 最近会话 / 会话消息 |
| `POST /api/chat`、`/ws/chat` | 对话（需要你确认的命令只能在 WebSocket 实时对话中批准；`POST /api/chat` 中会被拒绝） |
| `GET/PUT /api/settings/approval` | 读取 / 修改命令审批模式 |
| `GET /api/update`、`POST /api/update/check`、`PUT /api/settings/update` | 更新状态（`current`、`latest`、`url`、`notes`、`available` 等，仅读缓存）/ 立即检查（30 秒内重复返回 429）/ 开关自动检查 `{"enabled":true}` |
| `GET /api/bots`、`PUT /api/bots/:id`、`PUT /api/bots/:id/enabled` | Bot 列表 / 修改 / 启停 |
| `GET /api/usage` | Token 用量 |
| `POST /api/attachments`、`GET /api/attachments/:id/content` | 上传 / 读取本人附件 |
| `POST /api/servers/:id/test` | SSH 测试；可带 `{"fingerprint":"SHA256:…"}` 确认首次指纹 |
| `POST /api/servers/:id/host-key/reset` | 清除已保存的主机指纹 |
| `GET /api/monitor`、`POST /api/servers/:id/probe/token` | 探针状态 / 生成上报凭据 |
| `POST /api/probe/report` | 节点上报（Bearer 节点凭据，不能访问其他接口） |
| `GET/POST /api/assets`、`PUT/DELETE /api/assets/:id` | 资产与订阅 |
