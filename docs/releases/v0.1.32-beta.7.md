# 任务生命周期收紧：实时活动可见可停、按 Bot 并发与全链路取消

- **实时任务活动与可见停止**：任务卡片的活动流实时反映模型调用与工具执行的
  起止；进行中的模型活动在操作员暂停或取消任务时立即标记为「已中断」，请求
  本身在网络上被取消（httptest 服务器实测收到请求断开），不再只是状态翻转。
- **按 Bot 并发的持久任务**：不同 Bot（不同会话）的任务同时运行；同一会话内
  的任务严格串行，重复调度不会绕过会话槽位，前一个窗口释放后下一个才开始。
- **全链路取消范围**：取消或暂停一个任务会停掉它的模型 HTTP 请求（真实
  context 传递到模型调用）、本地工作区命令的整个进程组、属于该任务的后台
  作业（按 Bot + 任务号精确匹配，不误伤其他任务或其他 Bot 的作业），以及
  该任务派生的子任务；其他 Bot / 会话的任务不受影响。
- **调度竞态修复**：窗口的取消句柄在任务认领前注册，暂停/取消不可能错过
  在途模型操作；窗口启动前同时检查运行上下文与持久化 running 状态，过期
  窗口不再为已暂停/已取消的任务调用模型；派工子任务的激活改为注册表原子
  操作，父任务已暂停/取消/子任务已独立取消时拒绝复活过期快照里的排队子任务。
- **回归验证**：新增确定性测试覆盖——两个 Bot 并行且取消 A 后 B 继续完成、
  同会话串行、真实 HTTP 请求取消（暂停与取消两条路径）、活动流 running →
  interrupted 状态迁移、子任务激活竞态拒绝与正常放行。
- **已知限制**：后台作业状态仍在进程内，重启后不可查询（沿用既有行为）；
  本轮验证基于本地单测与竞态检测，尚未在生产长任务中验证。
