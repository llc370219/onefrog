# 预览服务器

在一台服务器上常驻一个预览版面板，自动跟随最新推送的 PR，打开网址就能看效果。它和正式面板是两个独立实例：端口、数据、账号都分开，互不影响。

## 原理

- 每次有 PR 推送，GitHub 上的 `Preview image` 流程会构建镜像并打上 `ghcr.io/llc370219/onefrog:preview` 标签（同时有 `pr-<编号>`）。正式版的 `latest` 和 `vX.Y.Z` 不受影响。
- 预览服务器每 5 分钟检查一次 `preview` 镜像，有新版本就自动更新。

## 安装（在服务器上用 root 执行一次）

```bash
curl -fsSL https://raw.githubusercontent.com/llc370219/onefrog/main/install.sh | \
  OF_INSTALL_DIR=/opt/onefrog-preview OF_PROJECT=onefrog-preview \
  OF_PUBLISH_PORT=8090 OF_VERSION=preview OF_UPDATE_CHECK=0 bash

cat > /etc/cron.d/onefrog-preview <<'EOF'
# 每 5 分钟拉取最新预览镜像，有变化才重建容器
*/5 * * * * root cd /opt/onefrog-preview && docker compose -p onefrog-preview pull -q && docker compose -p onefrog-preview up -d --remove-orphans >/dev/null 2>&1
EOF
```

安装结束会打印预览面板的地址（`http://服务器IP:8090`）、用户名和初始密码，第一次登录需要改用户名和密码。

- 已有的正式面板（默认 `/opt/onefrog`、8080 端口）不会被改动。
- 预览版不检查正式版更新（`OF_UPDATE_CHECK=0`），版本号显示为 `pr-<编号>`。
- 端口由 Docker 直接发布，ufw 等防火墙规则通常拦不住它；不想对外开放就加 `OF_BIND_ADDR=127.0.0.1`，再用 SSH 隧道访问。

## 日常使用

PR 推送后大约 5–10 分钟（构建约 3–5 分钟，加上最多 5 分钟的检查间隔），刷新预览地址就是新版本。想马上更新，可以在服务器上执行：

```bash
cd /opt/onefrog-preview && docker compose -p onefrog-preview pull && docker compose -p onefrog-preview up -d
```

## 卸载

```bash
rm -f /etc/cron.d/onefrog-preview
cd /opt/onefrog-preview && docker compose -p onefrog-preview down -v
rm -rf /opt/onefrog-preview
```
