# 运维会话下线，AI 助理成为唯一聊天入口

OneFrog v0.1.33 正式发布。原来的「运维会话」已移除，「AI 助理」（Frog Bot）移到它原来在主菜单里的位置，现在面板里只有这一个聊天入口。

## 变化

- 主菜单现在是：面板、AI 助理、模块、服务器、Bot、密钥保险箱、变更记录。AI 助理在第二项，就是原来「运维会话」的位置；原来单独的「AI 助理」标签合并进来，不再重复。
- 移除「运维会话」页面：Bot 单聊、隔离项目、收件箱和自动化对话列表、项目工作记忆，以及对话里的附件上传。
- 移除「代码工作区」页面。
- 服务器页的「交给 Bot」和密钥保险箱的「发给助理」会打开 AI 助理，并把内容放进输入框。
- 服务监控和订阅页的「让 Bot 检查」改由面板首页的主控 Bot 执行，结果显示在面板卡片上，命令仍要审批。
- 自定义模块的「AI 改造」和「修复」会把要求填进本页的构建器，不再跳去对话。
- Bot 页去掉了每个 Bot 的「对话」按钮。
- 自动化：普通 Bot 的运行在等待审批或运行中时，卡片下方直接显示任务卡，可以批准、拒绝、暂停或停止。Frog Bot 的运行仍在 AI 助理里查看。

## 接口

- 移除 `POST /api/chat`、`/ws/chat`、`GET /api/sessions`、`DELETE /api/sessions/:id`、`/api/sessions/:id/project-memory*` 和 `/api/workspace*`。
- 保留 `/api/tasks*`、`GET /api/sessions/:id/messages`、`/api/attachments`、`/api/frog-bot*` 和其他接口。面板任务卡、自定义模块构建器和自动化仍然使用这些接口。

## 升级须知

- 升级会保留账号、设置、服务器、保险箱、Bot、自动化和 Frog Bot 的数据，容器会重启。
- 没有数据库迁移，也不删除数据。原来运维会话里的对话、消息和项目记忆仍留在数据库里，只是页面上不再显示，也不会搬进 Frog Bot。
- 登录、审批、密钥保险箱、「只自动安装正式版」的更新策略和自动化调度都不变。

## 已知限制

- 无法再在网页上打开旧的单聊、隔离项目和收件箱对话。Bot 之间用 `message_agent` 发的消息仍在后台处理，但网页上不再有地方查看这些收件箱对话。
- 无法再在网页上用代码工作区开发仓库。
- Frog Bot 不能创建或修改自定义模块，这类改动请在「模块 → 自定义模块」的构建器里做。

## 升级方式

在面板「设置 → 关于与更新」检查并升级；也可以在安装 OneFrog 的服务器上执行：

```bash
curl -fsSL https://raw.githubusercontent.com/llc370219/onefrog/main/install.sh | sudo OF_CHANNEL=stable bash
```

使用自定义安装目录的用户需继续指定原来的 `OF_INSTALL_DIR`。
