# 持久自主任务运行时：本地工作区、后台作业与独立模型审批

- **持久自主任务运行时**：任务接受后写入加密任务文件，由后台 Runner 在自己的
  goroutine 中执行，断线或刷新页面不会取消任务；支持暂停、恢复与取消。任务
  卡片以活动流展示进度，已完成计划的段落是静态的完成区间（进度条内不再渲染
  数字），另有收尾消息、验证证据（finish 需要最后一次变更之后的只读观察）与
  未知副作用核验门。
- **独立模型审批（三态）**：审批模型返回 allow / deny / ask。allow 直接放行，
  deny 直接拒绝，ask（以及模型不可用或结果无法解析）一律转人工审批卡片，
  绝不静默放行；风险等级只是决策证据，不改变 allow 的结果。
- **隔离项目与 Bot 记忆**：原群聊更名为隔离项目，项目记忆仅在该项目中保留，
  不读写 Bot 私有记忆。每个 Bot 有独立私有记忆，Bot 之间通过 ask_agent 派工
  或 message_agent 交接结论，而非共享记忆池。
- **显式本地工作区**：任务在操作员明确允许的目录内读写、搜索、编辑文件并执行
  命令。允许列表来自 `OF_LOCAL_WORKSPACE_ROOTS`（ENV-only，为空即整个功能
  关闭），命令执行需要单独的 `OF_LOCAL_COMMAND_EXECUTION=1`，两者都是操作员
  显式开启，运行期不可更改。路径解析用 os.Root 防护，敏感文件统一拒绝；edit
  带 revision 校验，write 原子落盘。
- **后台作业**：构建、测试、迁移等长命令可用 `job_start` 以真实后台进程运行，
  `job_status` / `job_cancel` / `job_wait` 查询与等待；作业属于启动它的任务，
  结束后保留一段时间供查询。
- **Docker 部署的诚实说明**：容器内的 `local` 指容器内文件系统与容器进程权限。
  要操作宿主机项目，必须由操作员显式挂载项目目录，或通过已接入的 SSH 服务器；
  面板不会"魔法地"访问宿主机。命令以 OneFrog 进程的系统账号权限执行，
  **这不是沙箱**。
- **已知限制**：作业状态存在进程内，服务重启后不可查询，恢复的任务收到
  "作业结果未知，未重放"，必须只读核验工作区现状；未知副作用的变更调用不会
  自动重放，需要核验后才能 finish。
- **验证范围**：本测试版经过本地单测与 UI fixture 验证，尚未在生产环境的真实
  长任务中验证。
