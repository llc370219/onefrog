# 测试版：探针卡片改用分段条和三网历史色块

按参考图重新排版了探针卡片：

- **标题行**：根据资产里的地区或服务器名（如 `TYO-xxx`、`洛杉矶`）显示国旗，旁边是名称、在线状态和运行时间。
- **配置行**：地区 · 核数 · 内存 · 磁盘 · 系统，后面的标签显示资产里登记的套餐。
- **资源**：CPU、内存、磁盘、负载改成两列分段条，数值更大。超过 75% 变黄，超过 90% 变红。
- **网络**：左边是实时上传 / 下载速率，右边是本月出站 / 入站流量。
- **流量额度**：「资产与订阅」新增「月流量额度（GB）」和「流量计费方式」，可选双向、只算出站、只算入站、取较大者。填写后卡片显示「已用 / 额度」和进度条。
- **三网延迟**：电信、联通、移动各一行，显示当前延迟和丢包，下面是最近 18 次检测的色块。绿色正常，黄色偏高，橙色较高，红色很差或超时。
- 剩余天数、续费金额和运行中的服务保留在卡片底栏。

验证：Go 测试（新增流量额度校验）、前端类型检查通过；用模拟上报和资产记录在浅色 / 深色、桌面 / 390px 截图核对。
