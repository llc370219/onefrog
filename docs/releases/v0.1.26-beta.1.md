# 测试版：浅色主题、发布渠道与安全加固

这是 v0.1.26 的第一个测试版，只推送给装了测试版的机器，正式版安装不会收到提示。

### 界面
- 新增浅色主题，默认跟随系统；顶栏右上角或「个人账号 → 外观」可以切换跟随系统 / 浅色 / 深色。
- 两套主题都改为暖色中性底，强调色用绿色；页面和弹窗标题使用衬线字体，按钮改为小圆角。

### 安全
- 登录失败只按来源 IP 限速：同一 IP 输错 5 次后锁定，时间从 1 分钟起翻倍、最长 30 分钟；不再锁定账号本身，别人无法故意输错把管理员锁在门外。
- Bot 的模型接口密钥不能再通过 `{{secret:…}}` 写进服务器命令。

### 发布与升级
- 新增正式版 / 测试版两个渠道。测试版版本号形如 `v0.1.26-beta.1`，镜像标签 `beta`；面板「设置 → 关于与更新」会标出「测试版」，并提示新的测试版。
- 安装测试版：`curl -fsSL https://raw.githubusercontent.com/llc370219/onefrog/dev/install.sh | sudo OF_CHANNEL=beta bash`

### 构建与开发
- Docker 构建复用依赖缓存，只改前端时不再重新编译后端；前端拆分 React 和图标库，升级后浏览器可继续使用缓存。
- 新增 `scripts/dev.sh`，一条命令在本机预览任意分支或 PR。

验证：Go 全部测试、前端构建、安装脚本检查和 Docker 启动测试均通过；浅色 / 深色在桌面和 390px 窄屏下逐页核对。
