# 服务器监控、订阅管理与面板体验更新

OneFrog v0.1.26 正式发布。本次汇总 beta.1 至 beta.11 的更新，重点完善服务器监控、三网线路检测、流量展示和订阅管理，让日常查看与操作更集中。

## 服务器状态，一张卡片看清

服务器卡片重新排版，集中展示地区、配置、在线状态、运行时间，以及 CPU、内存、磁盘、负载和实时上下行速率。资源占用采用分段条，三网检测保留最近 18 次结果色块，便于观察变化；服务器详情可查看本月、上月流量等信息。

## 流量展示统一，额度可以直接设置

未设置额度时，左侧保留流量图标和标题，右侧按 **Out / In / Total** 展示本月用量，下面用两种颜色的分段方块显示出入流量构成。

点击「设置额度」即可填写每月额度和计费方式；已设置时，点击「双向」等计费方式文字即可修改。支持双向、只算出站、只算入站、取两者较大值。保存后卡片更新为「已用 / 额度」。尚未登记资产的服务器会先进入资产登记。

## 三网检测可选省份，配置有明确反馈

支持选择省份查看电信、联通、移动的延迟与丢包率，修复了选择省份后无法应用的问题。可以更换省份、调整检测间隔或关闭检测，应用过程中显示进度及结果。

线路检测与资源上报独立运行，默认每 60 秒检测一次，每个目标尝试 3 次，并加入错峰和失败退避。界面统一显示「丢包率」；三网使用 TCP 连接检测，这个数值表示连接尝试失败的比例，包含超时、拒绝连接等情况，不等同于 ICMP 数据包丢包率。

## 订阅管理，服务器之外也能记

域名、软件会员和其他订阅都可以登记，无需关联服务器。首页与订阅页统一展示 **订阅数、7 天内到期、折合月费、历史订阅**，首页新增「即将到期」数量。

折合月费默认使用 USD，可切换显示币种；原始金额和币种保留，按参考汇率估算，不支持换算的部分会单独列出。到期且未启用续费、或已手动结束的订阅归入历史，记录保留，也可续费恢复。

## 界面与 AI 协作体验

新增跟随系统、浅色、深色三种外观选择，自定义模块同步适配主题。首页卡片和手机布局更紧凑，内置 Bot 提示词与协作汇报方式重新整理，让回复、操作和验证结果更清楚。

同时完善登录失败按来源 IP 限速的逻辑，并阻止模型接口密钥通过密钥占位符写入服务器命令。正式版与测试版渠道独立提供更新提示。

## 升级方式

在面板「设置 → 关于与更新」检查并升级；也可以在安装 OneFrog 的服务器上执行以下命令，安装或切换到正式版：

```bash
curl -fsSL https://raw.githubusercontent.com/llc370219/onefrog/main/install.sh | sudo OF_CHANNEL=stable bash
```

使用自定义安装目录的用户需继续指定原来的 `OF_INSTALL_DIR`。原目录升级会保留账号、设置和数据，升级时容器会重启。

**已有探针需要同步更新：** 升级面板后，在对应服务器的三网设置中点击一次「保存并应用」，以更新采集脚本并启用独立检测与退避策略。仅升级面板镜像不会自动替换远程节点的脚本；手动部署的探针需手动更新并重启。
