# 测试版：页面排版与内置提示词优化

### 页面排版
- 去掉页头和品牌名下的英文小标签，页面只保留中文标题和一句说明。
- 说明文字整体放大一档，原来 9–11px 的小字更容易看清。
- 面板首页的统计数字不再补零（显示 4，而不是 04）。
- 宽屏下内容区最宽 1280px，不再铺满整个屏幕。
- 还没接入探针的服务器显示为一张简短的卡片，说明缺什么、怎么接入，不再显示一排「—」。首页能一次看到更多服务器和模块。

### 自定义模块跟随主题
- 自定义模块原来只有深色样式，在浅色主题下文字几乎看不清。现在会跟随面板的浅色 / 深色自动切换，按钮和强调色也统一为绿色。

### 内置提示词
- 主控提示词重新整理为「先回答再动手 / 选对工具 / 对话节奏」几节，修正了把查日志、改配置误导到面板工具的说法。
- 自定义模块的沙箱说明合并为一份，并说明可用的主题配色变量，生成的模块会自动适配浅色和深色。
- 协作 Bot 不再收到与"不要转派"相矛盾的协作说明，汇报格式统一为结论、改动和验证结果。
- 审批模型只输出 JSON，风险等级定义与命令风险一致。安全规则和工具名称保持不变。

验证：Go 全部测试与前端类型检查通过；浅色 / 深色、桌面 / 390px 窄屏逐页截图核对；自定义模块在两套主题下实际渲染核对。
