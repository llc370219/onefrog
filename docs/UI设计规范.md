# UI 设计规范

面向贡献者。新页面和社区模块沿用这里的角色，不另起一套样式。设计变量的唯一来源是 `web/src/index.css` 开头的主题块；本文说明怎么用。

## 原则

- 浅色和深色两套主题，默认跟随系统，用户可在顶栏或「个人账号 → 外观」切换。两套都是暖色中性底、细线性图标，强调色是和青蛙 logo 呼应的绿色。不加渐变；分层主要靠表面色和 1px 边框，弹层可用很轻的阴影。
- **不写死颜色**，一律用下面的变量，这样两套主题才能同时成立。界面改动要在浅色和深色下都看一遍。
- 主操作是绿色实心按钮（`--accent` 底、`--on-accent` 字），一个区域只有一个。危险操作不铺实心红，先打开对话框并写出对象名称再确认。
- 状态用圆点加文字表达，不只靠颜色。

## 颜色变量

| 变量 | 用途 |
| --- | --- |
| `--canvas` | 页面底 |
| `--base` | 侧栏、二级目录、右侧上下文栏 |
| `--s1` / `--s2` / `--s3` | 卡片 / 抬起一层（选中项、次级按钮）/ 再抬一层（悬停、头像底） |
| `--field` / `--inset` | 输入框 / 嵌在卡片里的凹陷区域 |
| `--popover` / `--composer` / `--bubble` | 对话框与菜单 / 对话输入条 / 用户消息块 |
| `--code-bg` | 命令、日志、代码块底色 |
| `--fg` / `--fg2` / `--fg3` / `--fg4` | 主文字 / 次文字 / 说明与分区标题 / 占位与弱元信息 |
| `--line` / `--line2` | 默认分割与卡片边 / 输入框与对话框边 |
| `--accent` / `--accent-hover` / `--on-accent` | 主按钮、焦点框、开关、选中态 / 悬停 / 强调色上的文字 |
| `--ok` / `--warn` / `--danger` | 成功 / 警告 / 危险。只用于文字、状态点或 6%–10% 的淡底 |
| `--ink` | 半透明叠色的基色：`color-mix(in srgb,var(--ink) 6%,transparent)` 用于悬停、淡底，不要写 `#ffffff10` |
| `--tone0`–`--tone3` | Bot 头像的四种色调 |

新增变量时，浅色块和两个深色块（`:root[data-theme=dark]` 与 `prefers-color-scheme:dark`）都要加，两个深色块保持一致。canvas 绘图用 `web/src/theme.ts` 的 `cssVar()` 取色。

## 圆角

| 角色 | 半径 |
| --- | --- |
| 按钮（含主按钮） | 10px |
| 菜单项、小卡片 | 8px |
| 侧栏当前项、列表悬停块 | 12px |
| 模块卡片、设置分组 | 16px |
| 对话框、底部输入条 | 24px |
| 图标按钮、头像、状态点 | 999px |

嵌套时内圆角 = 外圆角 − 内边距。

## 文字

- 拉丁文和数字用 Inter（`@fontsource/inter`），中文用系统字体（PingFang SC、Noto Sans SC、微软雅黑），等宽用 IBM Plex Mono（`@fontsource/ibm-plex-mono`）。
- 页面标题、对话框标题、品牌名用衬线字体 `var(--font-serif)`（系统衬线体：macOS 上中文为宋体），正文和控件不用衬线。
- 字重只用 400 和 500。字号：元信息 13px，控件 14px，正文 15px，卡片/对话框标题 16px，页标题 22px（一页一个）。
- 命令、路径、密钥名、日志、状态码用等宽 13px；表格数字用等宽数字。

## 图标

统一使用 `lucide-react`，单色线性，默认 16px（顶栏和输入条可 18px），颜色跟随文字。同一含义全站用同一个图标；纯图标按钮是圆形并带文字提示；不用 emoji 当界面图标。

## 组件

- **按钮**：默认高 36px，对话框主按钮 44px，表格内 32px。禁用为 40% 不透明度；加载时保留文字并在右侧显示转圈，宽度不跳。
- **卡片**：`--s1` 底、16px 圆角、`--line` 边框、16px 内边距；可点击的整卡才有悬停。
- **对话框**：宽不超过 420px（设置窗口除外）、24px 圆角、50% 黑色遮罩，支持 Escape 关闭与焦点限制，关闭时清空敏感表单。密钥明文只出现在对话框里，不进对话气泡。
- **输入条**：24px 圆角、`--s2` 底；焦点只提亮边框，不加彩色光环。
- **对话**：Bot 回复直接铺在画布上；用户消息放在 `--s2` 的 16px 圆角块里；工具调用和命令输出嵌在回复下方，内容等宽。审批拦截用危险色淡底，放在对话流或应用内对话框中，不使用浏览器默认弹窗。审批对话框底部只有「拒绝」和「批准执行」两个按钮，右对齐，手机上等宽并排。
- **选项卡片**：`--s1` 底、16px 圆角卡片，问题一行，选项是 8px 圆角按钮（多选带方框）；可补充说明时下方是输入框和「提交选择」。回答后卡片去掉底色，未选项降到 40% 不透明度，已选项带对勾。选项文字一律按纯文本显示。
- **列表**：行高 40px、14px 字号，悬停白色 4%。日志区使用基础黑底和等宽字体，不做绿色终端主题。

## 间距与动效

间距基数 4px，常用 8、12、16、24；页面边距 24。悬停与颜色变化 150ms；对话框和侧栏 200ms，只做透明度和最多 4px 位移。系统开启「减少动态效果」时只保留颜色变化。窄屏下主菜单收成图标栏，表格在容器内横向滚动。
