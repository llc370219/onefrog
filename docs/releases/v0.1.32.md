# Frog Bot 成为 AI 助理

OneFrog v0.1.32 正式发布。「AI 助理」改由 [Frog Bot](https://github.com/llc370219/frog-bot) v0.1.2 驱动，并且只用 OneFrog 自己的登录、模型、密钥保险箱和自动化，不再另起一套。本版同时包含 v0.1.32 测试版（beta.1 到 beta.11）里的全部改动。

## AI 助理（Frog Bot）

- 聊天层先回答你，耗时的事交给后台 Agent。任务在服务器上继续跑，刷新或关掉页面也不会中断；任务卡可以暂停、恢复、取消和重试，正在工作时一直有进度显示。
- 长任务会自动压缩上下文，不会因为对话太长而失败。事件日志写入更稳，断电留下的半行数据会在启动时自动清理。
- 密钥卡片直接存进「密钥保险箱」，不会进入聊天记录，助理也看不到明文；使用时写成 `{{secret:NAME}}`，每次都要你确认，输出里的密钥值会被遮盖。
- 在对话里说「每天 9 点帮我……」，确认审批卡片后会在「模块 → 自动化」里新建一条，执行者是「Frog Bot（AI 助理）」。也可以直接在自动化页面选它。需要你处理时，自动化显示「等待处理」。
- 操作服务器时，每条远程命令都要你单独批准一次，并经过 SSH 指纹校验和审计。Frog Bot 不能在面板所在的宿主机上执行 Shell。
- 每个账号有自己的 Frog Bot、对话和工作区，互相看不到；数据按账号加密保存在 `OF_DATA_DIR/frog-bot/`，备份与迁移会一起打包。
- 原来的群聊、Bot 专属会话和代码工作区移到「运维会话」，记录照常保留。

## 测试版里的其他改动

- 加密备份恢复，以及用一次性迁移码在线搬家。
- 代码工作区：通过 SSH 打开宿主机上的仓库。
- 运维会话的持久后台任务运行时、独立模型审批、任务进度卡片、按 Bot 并发与全链路取消。
- 群聊按项目隔离记忆；聊天时可以连续发消息、直接回答和纠正当前轮。
- 面板探针一排最多三张；补回默认主控「服务器管理」。
- 设置里可以切换正式版和测试版更新渠道，旧升级程序切测试版时不再假装成功。

## 更新

- 「自动安装新正式版」只会自动安装正式版。选了测试版渠道也不会自动装测试版，需要你手动点「立即升级」。

## 升级须知

- 升级会保留账号、设置、服务器、保险箱和自动化，容器会重启。
- Frog Bot 第一次打开时是空对话。原来的会话在「运维会话」里，不会自动搬过来。
- 自动化里已有的计划不受影响，仍由原来选的 Bot 执行。

## 已知限制

- AI 助理和运维会话目前仍是两个聊天入口：Frog Bot 负责日常对话和后台任务，多 Bot 群聊和代码工作区仍在运维会话里。之后会继续合并。
- Frog Bot 只能引用由大写字母、数字和下划线组成的密钥名（例如 `GITHUB_TOKEN`），其他名字的密钥它看不到。
- Frog Bot 的定时计划每周只能选一天，时间按 OneFrog 服务器的时区。
- 这一版用模拟模型和本地数据库测试过登录、对话、后台任务、审批卡片、密钥卡片和自动化；还没有在真实模型和多台真实服务器上长时间运行。

## 升级方式

在面板「设置 → 关于与更新」检查并升级；也可以在安装 OneFrog 的服务器上执行：

```bash
curl -fsSL https://raw.githubusercontent.com/llc370219/onefrog/main/install.sh | sudo OF_CHANNEL=stable bash
```

使用自定义安装目录的用户需继续指定原来的 `OF_INSTALL_DIR`。
