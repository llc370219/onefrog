# 测试版：服务器探针卡片重做，新增三网延迟和月流量

### 探针卡片
- 卡片改小，宽屏一行三张，一屏能看到更多服务器。
- 每张卡片包含：基础信息（系统、架构、核数、内存、磁盘）、在线状态和已运行时间；CPU、内存、磁盘、负载；实时上下行速率；本月入站、出站和双向流量；三网延迟和丢包；剩余天数和续费金额；运行中的服务。
- 负载进度条按核数折算，悬停可看 1 / 5 / 15 分钟负载。
- 服务器详情里新增本月流量、上月流量和三网测速省份。

### 三网延迟
- 第一次配置探针时要先选「三网延迟测哪个省份」，也可以选「不测三网」。支持 31 个省级地区，测该省电信、联通、移动节点的延迟和丢包。
- 用 TCP 握手（80 端口）检测，很多运营商节点不回 ICMP，ping 测不出来。
- 让助手安装探针时，如果没说省份，助手会先问你。

### 流量统计
- 面板按自然月累计每台服务器的入站和出站流量，节点重启后计数清零也会接着累加。上个月的总量会保留。

### 面板首页
- 顶部统计卡片更矮，模块卡片不再被同一行最高的卡片撑出大片空白。

**升级提示**：已经装了探针的服务器需要重装一次探针才能测三网（旧版探针不支持 TCP 检测）。在卡片上点「选择省份」，或对助手说「给 xxx 重装探针，三网测广东」。流量从升级后的第一次上报开始统计。

验证：Go 测试、探针脚本单元测试（TCP 检测通 / 不通 / 非法主机）、前端类型检查通过；用模拟上报在浅色 / 深色、桌面 / 390px 窄屏截图核对首页和服务器页。
